## Valko-UI Components

### Components

- Added the new `Rating` component with support for:
  - Single and half ratings.
  - Hover previews and animated selection feedback.
  - Custom icons, colors, sizes, disabled, and readonly states.
  - Accessible ARIA roles and screen reader support.

### Exports

- **valko-ui.css:**
  - Added the reusable `pop` animation, available for use across components.

### Types

- Added `Rating` component types.

### Tests

- Added unit tests covering rendering, interaction, accessibility, and selection behavior for the `Rating` component.

## Valko-UI Docs

- Added documentation and examples for the `Rating` component.
